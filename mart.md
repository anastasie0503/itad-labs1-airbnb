# Аналитическая витрина: Метрики объявлений

## 1. Модель
- **Выбранный вопрос:** В каких районах Нью-Йорка и типах помещений различаются число объявлений, медианная цена за ночь и средняя доступность?
- **Гранулярность:** Одна строка представляет уникальную комбинацию **Района** (`neighbourhood_group`) и **Типа помещения** (`room_type`).
- **Ключ:** Составной ключ: `neighbourhood_group` + `room_type`.
- **Меры:**
  - `listings_count` — количество объявлений.
  - `median_price` — медианная цена (только для `price > 0`).
  - `avg_availability` — среднее число доступных дней.

## 2. Сопоставление полей
| Поле в витрине | Поле в staging | Преобразование | Смысл |
| :--- | :--- | :--- | :--- |
| `neighbourhood_group` | `neighbourhood_group` | Без изменений | Район Нью-Йорка |
| `room_type` | `room_type` | Без изменений | Тип жилья |
| `listings_count` | `id` | `COUNT(*)` | Число объявлений |
| `median_price` | `price` | `MEDIAN(price)` | Медианная цена за ночь |
| `avg_availability` | `availability_365` | `AVG(availability_365)` | Средние дни доступности |

## 3. Проверки и ограничения
- Выполнена проверка записи и чтения данных из `mart`.
- Исключены объявления с нулевой/отрицательной ценой для расчета медианы.
- **Ограничение:** Витрина отражает статичный снимок на дату загрузки.
