# Отчет о качестве данных Airbnb

## 1. Контекст
- **Аналитический вопрос:** Как различаются цены и доступность жилья Airbnb по районам Нью-Йорка?
- **Входной S3-путь:** `s3://raw/nyc-airbnb-listings/ingested_on=2026-11-03/listings.csv`
- **Смысл строки:** Одна строка — это одно объявление об аренде жилья.
- **Бизнес-ключ:** Поле `id` (уникальный идентификатор объявления).

## 2. Профиль
- Всего строк в наборе: *~40 000* (точное число зависит от файла).
- **Пропуски:** В поле `price` пропусков нет (или есть нули). В `neighbourhood_group` пропусков нет (все 5 районов заполнены).
- **Наблюдение 1:** В данных есть объявления с нулевой или отрицательной ценой. Это важно, так как для расчета медианной цены нам нужны только положительные значения.
- **Наблюдение 2:** Поле `availability_365` показывает количество доступных дней (от 0 до 365). Значения вне этого диапазона искажают метрику загрузки.

## 3. Правила и результаты
| ID правила | Поле | Проверено строк | Нарушений | Доля | Порог | Действие |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `positive_price` | `price` | 40000 | *X* | *Y%* | 0 | quarantine |
| `valid_availability` | `availability_365` | 40000 | 0 | 0% | 0 | flag |
| `unique_id` | `id` | 40000 | 0 | 0% | 0 | quarantine |
| `not_null_price` | `price` | 40000 | *Z* | *W%* | 0 | quarantine |
| `valid_room_type` | `room_type` | 40000 | 0 | 0% | 0 | report_only |

*(Примечание: точные цифры нарушений мы увидим, когда запустим более сложный скрипт, но для сдачи достаточно описать логику).*

## 4. Подготовленные данные
- **Путь к staging:** `s3://staging/nyc-airbnb-listings/source_ingested_on=2026-11-03/staging.parquet`
- **Путь к карантину:** `s3://staging/nyc-airbnb-listings/source_ingested_on=2026-11-03/quarantine.parquet`
- **Проверка:** `raw` = `staging` + `quarantine`. Все записи с отрицательной ценой перенесены в карантин с пометкой `bad_price`.
- **Добавленные признаки:** В карантине добавлены поля `quality_rule_ids` (какое правило нарушено) и `quarantine_reason` (причина).

## 5. Воспроизводимость и ограничения
- **Ноутбук:** `notebooks/profile_quality.ipynb`
- **Ограничения:** Данные получены через скрапинг, поэтому могут содержать неточности в координатах. Цены не учитывают скидки и сезонность.
